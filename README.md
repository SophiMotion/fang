# 3D 报价系统

原创 React + TypeScript + Three.js 工作台。批量导入模型，为每个零件单独设置工艺、材料、后处理与数量，完成可解释的费用计算、采样壁厚筛查与制造风险检查。

网站：**https://sophimotion.github.io/fang/**

## 使用

1. 首次进入显示标注为演示数据的项目；点击“新建报价”建立空项目，填写客户姓名、公司和编号。
2. 拖入模型。导入真实模型会替换演示零件。STL/OBJ 默认毫米，选中零件下方可修正源单位。
3. 逐件设置工艺、材料、后处理与数量；勾选后可批量设置。“价格资料”中的修改用于当前项目。
4. 打开“壁厚与风险”执行采样。“按工艺检测全部”采用每种工艺的建议阈值；风险规则可新增、修改、禁用或删除。
5. 导出 Excel、PDF 或完整项目备份。历史项目在“客户与报价”中继续编辑。

## 文件格式

| 格式 | 实际能力 |
| --- | --- |
| STL | 二进制/ASCII 网格，连通零件拆分、真实尺寸与体积 |
| OBJ | 多对象网格；显示材质不会自动等同于打印材料 |
| STEP/STP、IGES/IGS | OpenCascade WebAssembly 本地解析、三角化；统一毫米 |
| URDF | 基本几何与随附本地网格、静态装配；缺少附件明确报告 |
| F3D/F3Z | 识别为待转换；先从 Fusion 导出 STEP/STL，再导入 |

文件在浏览器中处理，不上传模型、客户或报价数据。详细能力见 [研究说明](docs/research.md)。

## 计算与适用范围

- 默认价格均为**示例值**，应根据真实设备、供应商及业务校准。
- 单件成本 = 体积 × 密度 × 材料单价 + max(单件加工起步价, 体积 × 加工单价) + 后处理。各费用先舍入到分，单件加价后乘数量，再减折扣、计税、加运费。
- 成本加价率不同于毛利率；折扣为减免比例；起步价是每件起步价。
- 体积由闭合且朝向一致的三角网格求得，不是精确 B-Rep 测量。无效或待转换项不计价，导出列明排除项。
- 几何检查包括开放边、非流形、退化面与朝向；**未验证所有自相交、壳体嵌套和制造缺陷**。可估价不表示生产验收合格。
- 壁厚是面积采样射线筛查，提供最小样本/P10/中位数/命中率。壁厚规则采用 P10，可能漏掉细小特征；未知不等于通过。
- 悬垂以模型 Z 轴为打印竖直方向，仅作筛查；设备尺寸按当前三轴方向比较，未自动优化摆放或生成支撑。
- 大模型受到浏览器内存和每件三角面限制；过大时请简化或拆分。

## 本地记录与导出

IndexedDB 自动保存项目和模型；清理浏览器网站数据会删除记录。数据属于当前网站地址及浏览器，请定期备份。

JSON 项目备份含模型与设置，恢复时重新计算几何并清除旧壁厚缓存，需重新检测。

Excel 有项目汇总、零件明细、风险检查及参数四张表，是静态数值快照。PDF 支持中文长文与跨页表格，采用高清图像页保证字体可用，文字不能搜索或选择。

## 开发与部署

需要 Node.js 22.12+。验证环境为 Node 22.23、npm 11；npm 10 的部分可选 peer 解析存在 Arborist 错误。

```sh
npx --yes --package npm@11 npm ci
npm run dev
npm test
npm run build
```

本地访问路径 `/fang/`。main 推送后 GitHub Actions 执行测试、构建和 Pages 发布。运行时依赖随站点打包，无外部 CDN。

`src/geometry` 为导入、几何、壁厚 Worker；`src/domain` 为报价和规则；`src/export` 为导出；`src/storage.ts` 为本地项目；`src/components` 为原创界面；`tests` 包含数值与持久化回归。设计、研究、审查与验收结果在 `docs`。

依赖许可证见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
