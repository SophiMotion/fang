# 浏览器本地 3D 报价系统技术研究

核查日期：2026-10-16。范围：参考站实现、浏览器静态部署的模型解析、体积与壁厚边界、风险规则及验收。已阅读 `task_brief.md` 和 `design.md`；本文件记录研究，不代表任何功能已经实现或验收通过。

## 结论与规格影响

现有规格没有研究层面的实际阻塞。推荐使用 Three.js 解析及展示网格、occt-import-js WASM 导入 STEP/IGES、three-mesh-bvh 加速本部件表面的空间查询。所有依赖与 WASM 应打包到站点，分析留在本机。

以下边界必须保持：

- F3D/F3Z 识别后列入待转换项，由用户在 Fusion 导出 STEP/STL 后重新导入；当前静态方案不声称直接解析该归档。
- CAD 三角化后的体积属于网格计算，壁厚属于采样筛查；不声称精确 B-Rep 测量、完整制造检验或真实失败概率。
- 渲染适配视图、拖动、分解与测量数据分离；模型真实单位换算是分析操作，不能复用展示缩放。
- 无法解析、几何无效、依赖缺失与测量未知的行不计入已完成报价，不能按零元成功处理。

## 解析方案与能力边界

| 输入/库 | 已核实能力 | 实施建议与限制 |
| --- | --- | --- |
| STL / Three.js STLLoader | 支持 ASCII、二进制；返回非索引 `BufferGeometry`；ASCII 多个 `solid` 对应不同 groups。[S3] | 以文件、solid 或连通分量拆分时保留来源。二进制 STL 不提供可靠业务部件树；不能承诺自动恢复原 CAD 装配语义。 |
| OBJ / Three.js OBJLoader | `parse(text)` 返回 `Group`；材质可经 MTLLoader 提供。[S4] | 遍历真实 mesh，过滤线/点等无实体表面对象。MTL 的渲染材质不是打印材料，缺 MTL 不应妨碍纯几何分析。对象命名和分组也不等同于可制造部件。 |
| STEP/STP、IGES/IGS / occt-import-js | 完全在浏览器运行；需要 JS 与 WASM；接受 `Uint8Array`，输出 `success`、层级、名称、网格、颜色及面对应三角形范围。`linearUnit` 默认 mm，允许 mm/cm/m/inch/foot；可设置曲面三角化偏差。[S2] | 导入固定请求 mm；保留可获得的名称和层级，测试重复实例与不同位置的组件。读取成功不等于实体有效；IGES 可能仅含开放曲面。公开导入结果没有直接提供精确实体体积、完整有效性证明或壁厚函数。 |
| URDF / urdf-loader | 可加载 link/joint 结构，通过 `packages` 映射包路径，并通过自定义 mesh loader 加载依赖。[S7] | 导入 URDF 及随附网格；本地依赖路径建立明确映射，缺失逐项报告。基础 box/cylinder/sphere 可以按 XML 参数建模；不能用近似碰撞体替代真实外观实体计价，不能同时计入 visual 与 collision 导致双算。 |
| F3D/F3Z | Autodesk 将其作为 Fusion 归档；带外部引用的设计涉及 F3Z，官方支持从 Fusion 导出其他格式。[S8] | 本次未找到可以推荐的成熟开源纯浏览器直接解析方案。采用已确认的“识别、提示转换、重新导入”路径，不把未验证的归档内部结构当稳定接口。 |

STL/OBJ 的导入坐标应当视为需要用户确认的长度单位，默认值必须可见。STEP/IGES 使用库的单位转换，不再盲目追加一次缩放。URDF 的机器人坐标、网格自身坐标及 mesh scale 应分别处理，使用标准尺寸用例核对，避免米和毫米混淆。

WASM 导入和大网格分析放 Worker。以独立任务 ID 防止旧任务覆盖新项目，取消时终止对应 Worker；分析失败保留可理解的错误。普通 Worker 即可作为静态部署基线，不依赖多线程共享内存；three-mesh-bvh 的并行 Worker 依赖 `SharedArrayBuffer`/跨源隔离，不能默认认为 GitHub Pages 已满足条件。[S5]

## 测量与分析约束

### 单位与几何所有权

建立不可被展示交互修改的分析数据：统一 mm 顶点、索引、来源、用户确认单位、真实导入变换与几何检查状态。渲染对象可从该数据生成，但相机适配、展示居中、零件平移和分解只能影响渲染。

内部统一 mm、mm²、mm³；`体积 cm³ = 体积 mm³ / 1000`；`实心等效重量 g = 体积 cm³ × 密度 g/cm³`。未实现切片与填充估计时，这不是 FDM 含填充、支撑、损耗的实际耗材重量，报价界面应保持估算口径清楚。

### 体积与网格检查

对有效、闭合、定向一致的三角网格可用有符号四面体求和：`V = Σ a·(b×c)/6`。计算前将参考原点移近几何，可减轻远离原点时的浮点抵消；该平移不能改变有效闭合实体体积。

至少分别统计退化三角形、重复面、边界边、非流形边及共享边方向冲突。STL 常为不共享索引的三角汤，拓扑检查需按位置建立独立的容差焊接映射，不能以渲染索引直接判定全部边开放，也不能让法线/UV 差异阻止同位置顶点归并。焊接容差应随模型尺度控制，避免吞掉真实薄缝。

“每条边恰有两个面”并不证明模型有效：自交、相互穿插的闭合壳、内腔朝向都可能使体积不可信。CGAL 的官方定义把闭合、自相交、体积交叠和朝向兼容分开处理；其 `does_bound_a_volume` 以闭合为前提，并明确自交输入不满足可靠使用条件。[S6]

不要对每个闭合壳分别取绝对值再求和，这会把内腔也加成材料。模型整体反向、局部反向及内腔壳的朝向需区分。自交等没有实施的检查显示“未检查”；不能把“没运行检查”显示为“通过”。不可信体积不作为正式已完成报价依据。

### 采样壁厚

three-mesh-bvh 提供首个/全部射线命中、最近点和几何查询；直接 MeshBVH 查询使用本地坐标，不能混用世界坐标或渲染缩放后的距离。它提供空间查询加速，并不自带制造壁厚分析。[S5]

建议在每个独立部件的分析网格上构建 BVH，按表面积分布采样。从表面向内部发射射线，使用与模型尺度匹配的小偏移，排除自身/相邻面的伪命中；用有效对面表面距离形成采样值。仅查询同一部件，附近其他零件不参与壁厚测量。先校验面朝向，不能用平滑渲染法线代替可靠的几何面方向。

工程判断：单方向射线距离是方向厚度估计，斜壁、孔边、凹面、尖角、曲面、极小薄区及错误法线可能导致偏差或漏检。增加采样/方向可改善覆盖，但不能宣称证明了全局最小壁厚。最近点查询容易命中原表面，也不能直接作为厚度。

输出至少包含采样方法、采样数、有效命中率、采样最小值/低分位值、薄壁占比和热图。若采样按表面积分配，才可合理将计数占比用于估计薄壁面积比例。无命中、无效几何或采样覆盖不足显示未知/需复核；不得显示绿色通过。设定时间/样本预算，避免高面数模型卡死页面。

### 风险规则

采用可解释规则引擎：名称、适用材料/工艺、指标、比较关系、阈值及单位、严重度、建议、启用状态。每项风险显示触发部件及测量依据；规则编辑应即时更新结果。未知指标应输出“无法判断”，不能通过类型转换把 `null` 变成 0。

包围盒用于当前评估摆放方向的设备包络筛查；不能以该结果断言不存在其他可放入的方向。悬垂角与打印方向相关；没有实现方向选择或切片分析时，标明所用方向及其近似性。风险标签不是经过真实制造数据校准的失败概率。

## 建议验收用例

以下是建议的验收标准，尚未执行。

| 用例 | 应观察的结果 |
| --- | --- |
| 10 mm 闭合立方体，ASCII STL/二进制 STL/OBJ | 尺寸 10×10×10 mm，体积 1 cm³；密度 1.24 g/cm³ 时实心等效重量 1.24 g，三种格式结果一致。 |
| 同模型 cm/m/inch 单位切换 | 长度比、面积比、体积比分别为 s、s²、s³；不能只更新尺寸显示而漏更新价格。 |
| 相同物体的 mm/inch STEP | 统一 mm 后尺寸和体积一致，无重复单位转换。 |
| 预览旋转、缩放、适配视图、居中、分解 | 体积、真实尺寸、重量、单价及总价保持不变；导出值也不变。 |
| STEP 多零件与同一部件多个放置实例 | 数量、名称、位置与重复实例统计可复核；不漏算、不因遍历父子层级双算。 |
| 缺面、翻转面、重复面、非流形边、自交 | 逐项报告；未实施检测显示未检查；不能仅凭外观看起来正常给出可靠体积。 |
| 带内腔模型与相交壳 | 正确扣除内腔；体积交叠不能简单相加冒充实体材料体积。 |
| 0.8/1.2/2.0 mm 平板、等厚空心盒 | 厚度和阈值结果可复核；热图位置与薄区对应；临界阈值比较关系清楚。 |
| 壁厚模型旁放另一个部件 | 壁厚结果不因邻近部件距离变化而变化。 |
| 同一曲面不同三角化精度 | 记录体积和厚度差异，确认显示网格近似性；CAD 导入成功不被当成精确测量保证。 |
| 三部件不同材料/工艺/后处理/数量 | 只修改一个部件时，仅其价格及项目汇总变化；不回写其他部件配置。 |
| F3D/F3Z、缺依赖 URDF、坏文件、超限文件 | 清晰报告待转换/依赖缺失/解析失败/超限，不生成虚构原模型，不出现零元成功行。 |
| 导入中取消、项目切换、连续导入 | 旧任务不覆盖新项目；页面可继续操作；无效项不阻止其他有效部件报价。 |
| 导出与本地恢复 | 页面、Excel、PDF 的客户、单位、数量、状态及金额一致；刷新恢复后重新分析结果一致。 |
