# 原创工作台视觉规格

来源：用户批准功能规格后要求从零设计；内置 imagegen 原创概念 work/concept.png，1543×1019，已由主智能体 view_image 检查。该图为视觉参考，金额/客户/示例尺寸以实际引擎数据为准。

- 结构：88px导航、64px顶栏；内容留白28px；横向客户字段；蓝色下划线tabs；模型面板与340px摘要，底部整宽编辑矩阵。
- 颜色：背景#F6F8FC，surface#fff，border#DDE3EC，text#1F2937，muted#74829A；blue#4285F4，red#EA4335，yellow#FBBC04，green#34A853。
- 字体：系统中文字体，正文14px、导航12px、标签12px、主标题24px、区标题17px；Tabular数字；输入/按钮明确继承字体与字号。
- 组件：轻边框8px圆角面板，36px按钮/表单，Lucide 18px线性图标，选中行#EAF2FF；不添加营销区或装饰性指标。
- 场景：明亮浅灰网格、实际3D几何、蓝色法兰/绿色壳体/黄色立板；相机可旋转缩放。真实几何与图中的示意细节可不同，不为了视觉改变测量。
- 上方文案：3D报价系统、本地工作空间、保存状态、导入项目、导出报价、报价工作台、新建报价、客户姓名、公司名称、报价编号、有效期、零件与报价、壁厚与风险、模型工作区、添加模型、适配视图、分解、线框、报价摘要。
- 手机：导航变横向按钮，客户2列，预览与摘要依次堆叠，零件矩阵保留横向滚动；主页面无水平溢出。
- 允许的必要偏差：项目数据/价格/风险动态计算；额外客户姓名/联系信息；模型基本几何细节；可访问性状态、忙态、未知结果/文件支持说明。
