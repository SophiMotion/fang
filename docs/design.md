# 3D 报价系统开发规格

## 目标与选择

提供打开网页即可使用的中文 3D 打印报价工作台。已比较浏览器本地版、多人共享后端版、分期版本；用户选择浏览器本地版，减少部署维护需求并将模型保留在本机。

## 界面与流程

Google 配色，白色及浅灰底，蓝色为主操作、绿/黄/红标识结果状态，零件使用四色区分。保留参考站工作台结构，优化留白、字体、密集表格和窄屏布局。

顶部：系统名称、项目/客户、保存状态、价格设置、导出。
左侧：批量文件导入、零件列表、筛选、选中部件及数量。
中央：3D 预览，可旋转、缩放、适配视图、隐藏/单独查看零件、分解视图，显示单位与尺寸。
右侧：选中零件的独立材料/工艺/后处理参数；报价分析、采样壁厚、风险分析标签页。
下方：逐零件明细、数量、体积、重量、成本、报价和状态，项目汇总。

客户字段包含客户姓名/公司、联系人、报价编号、日期、有效期与备注。可使用明显标记的示例模型体验，示例不混入新建空项目。

## 文件与几何

- STL（二进制与 ASCII）、OBJ：实际网格解析，按对象/solid 或连通部件合理拆分。
- STEP/STP、IGES/IGS：OpenCascade WASM 实际三角化，保留层级和零件名称，统一为 mm。体积标明来自三角网格计算。
- URDF：解析 link/joint，支持基本几何及随附本地网格文件；缺失依赖逐项报告，无法解析的部分不能获得虚构报价。
- F3D/F3Z：识别并列出待转换项，提供 Fusion 导出 STEP/STL 的操作提示，再导入完成分析。当前静态架构不宣称直接解析专有归档。
- STL/OBJ 提供 mm/cm/m/inch 单位选择，显示真实尺寸。显示缩放、移动和分解不改变分析几何。
- 显示网格闭合、退化/非流形及朝向检查结果；未完成的检查明确标示。无效网格不作为可靠体积和正式报价依据。
- 大文件有进度/忙状态、大小限制和失败说明，使用 Worker 避免长时间阻塞界面。

## 价格与商业数据

各部件独立工艺、材料、密度、单位材料价、加工价、加工起步价、后处理和数量。材料/工艺搭配需验证，不能出现树脂工艺配金属而不提示。

示例计算顺序：单件材料费 = 体积 cm³ × 密度 g/cm³ × 材料单价 元/g；加工费 = max(加工起步价, 体积 × 加工单价)；后处理费单独列示；单件基础成本求和后乘数量。项目加价比例、折扣、税率、运费按固定明示顺序计算，使用分币四舍五入并保持 UI、Excel、PDF 一致。利润选项明确是成本加价率，避免与毛利率混淆。默认参数标为示例并可修改保存。

未完成解析/无效几何的行保留状态，不计入已完成报价，导出显示排除项且不显示为零元成功。

## 壁厚与风险

采用 BVH 加速的多点射线采样检测本部件对面表面，提供采样厚度、薄壁比例、有效命中率和热图。明确为采样筛查，可能遗漏局部细小特征，不将包围盒最小尺寸当成实际壁厚；未知结果不能显示通过。

风险规则可新增、修改、启用/禁用、删除和恢复默认。规则包含名称、适用工艺/材料、指标、比较关系、阈值、严重度与建议。指标包括薄壁、超出设备尺寸、悬垂/支撑需求、几何异常；输出具体触发零件和依据，不输出未经校准的失败概率。

## 保存与导出

IndexedDB 保存当前项目与模型，保存失败会显示错误；配置在当前浏览器持久保存。可导出/导入项目备份。客户、报价、模型不上传服务器。

Excel：项目汇总、零件明细、风险及参数等工作表，包含数值单元格和清晰单位。
PDF：中文报价单，含客户、报价编号/日期/有效期、逐部件材料工艺后处理数量与单价、汇总税费和备注；支持多页表格，中文不乱码，不截断。

## 架构与发布

React + TypeScript + Vite，独立领域模块：文件解析、几何测量、壁厚 Worker、价格引擎、规则引擎、持久化、导出、展示。依赖打包到站点，避免运行依赖不可靠第三方 CDN。

GitHub 仓库 SophiMotion/fang；base=/fang/；GitHub Actions 构建与 Pages 部署。已获用户明确部署授权，验收后发布并回查线上地址。

## 验证

10 mm 立方体体积 1 cm³；不同单位缩放、缺面/坏文件、多个不同配置部件、薄板壁厚与独立部件隔离；价格加价折扣税费顺序与分币一致性；编辑规则立即更新；本地保存/恢复；导出文件可打开、中文可读、多页正常；桌面及手机布局和键盘操作；构建通过、独立 Reviewer 结论及线上回查。

已完成规格自审：无占位待办；专有格式、测量近似、示例价格及未知结果均有明确处理。
