# 任务简报

输入：用户原始需求、三张截图、参考站 http://sophistudio.com/stlquote/index.html 与后续确认。

## 已确认

1. 项目根目录 D:\3D报价系统；用户授权工程内部文件与子文件夹合理命名。
2. 尽量支持参考站全部格式：STL、OBJ、STEP/STP、IGES/IGS、URDF、F3D/F3Z。
3. 无需登录，模型与报价保存在当前电脑；发布到 SophiMotion/fang 并部署 GitHub Pages。
4. Google 蓝红黄绿配色；每部件独立材料、工艺、后处理、数量。
5. 增加客户名字，提供报价分析、壁厚分析、风险预测与可编辑风险规则。
6. 导出 Excel 和报价单 PDF。
7. 内置可编辑示例价格：材料费、加工费、后处理、起步价、利润、税费和折扣。

## 交付与验收

- 可运行并公开访问的实际应用、完整源代码、使用说明与限制说明。
- 混合配置三个部件，修改一个部件只改变其价格及总价。
- 真实导入及三维预览，几何分析与可视化缩放隔离。
- 客户与逐部件信息出现在 Excel/PDF；导出金额和页面一致。
- 单位、无效几何、缺失依赖、待转换文件明确报告。
- 本地保存/恢复，删除需用户主动操作；无后台上传模型。
- 独立审查通过后发布，验证线上核心流程。
